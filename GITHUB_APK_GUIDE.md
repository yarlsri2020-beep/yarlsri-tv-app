# YARLSRI TV – GitHub Android APK Build

## No local Flutter installation needed

1. Open https://github.com/new and create a repository named `yarlsri-tv-app` (choose **Private** if preferred).
2. Extract this ZIP on your Windows PC. Upload the **contents** (including the hidden `.github` folder) to the repository root using **Add file > Upload files**. Commit to the `main` branch.
3. Open the repository **Actions** tab. Enable workflows if prompted. Choose **Build YARLSRI TV Android APK**, then **Run workflow**. The workflow also runs on pushes to `main`.
4. Wait for a green checkmark. Open the completed workflow run and download the `yarlsri-tv-android-apk` artifact. Unzip it to get `app-release.apk`.
5. Copy the APK to an Android phone and install it (allow installing from the relevant source if prompted).

Note: This is a test APK signed with a debug-style/default build key generated by Flutter. For public Play Store release, configure your own signing keys, package ID, policy compliance and testing. This build has not been executed here. Live stream playback must be tested on real devices and depends on stream availability.

The workflow creates the Android native platform folder on GitHub, since this ZIP contains Flutter source rather than generated Android project files.
